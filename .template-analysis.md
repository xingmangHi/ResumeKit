# Template Analysis and Modification Plan

## Common Issues to Fix (Based on First Review)

1. **min-height → height**: `.container` uses `min-height: 29.7cm` allowing content stretch
2. **@media print font-size override**: Print sets different font-size (e.g. 13.5px vs 14px)
3. **@media print page-break-inside**: `.section { page-break-inside: avoid; }` on whole sections
4. **Geometry not shared**: Width/height/padding only in @media screen
5. **Border in screen affects content**: border-box with border may confuse geometry

## Modification Checklist Per Template

- [ ] Move `.page`/`.container` geometry to common rules (outside @media)
- [ ] Change `min-height` to `height: 297mm`
- [ ] Keep `padding` values in common rules (screen and print share)
- [ ] Move `border` and `box-shadow` to `@media screen` only
- [ ] Remove font-size override in `@media print`
- [ ] Remove `.section { page-break-inside: avoid; }`
- [ ] Add fine-grained break rules (`.item`, `.section-title { break-after: avoid; }`)
- [ ] Add `overflow: visible;` to detect overflow
- [ ] Preserve all visible text, placeholders, links, order
- [ ] Preserve style, color scheme, structure
- [ ] Do NOT add fake content or delete text
- [ ] Record original padding values for reference
